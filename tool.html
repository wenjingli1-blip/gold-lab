CRISPR Vector System

DECKO

Dual Excision CRISPR Knockout

Experimental Lentiviral vector Single-gene & genome-wide

Overview

DECKO (Dual Excision CRISPR Knockout) is a lentiviral vector system for efficient CRISPR-Cas9-mediated deletion of genomic regions — particularly suited to the study of long noncoding RNA genes, where deletion (rather than point mutation) is often required to avoid confounding effects on overlapping regulatory elements.

The system delivers two sgRNAs simultaneously, each targeting one side of the region of interest. Cas9-mediated cleavage at both sites results in deletion of the intervening sequence, including lncRNA exons and promoters. DECKO scales seamlessly from validating a single candidate gene to genome-wide pooled screens using sgRNA libraries.

DECKO is used in two stages: (1) design paired sgRNAs using CRISPETa, (2) clone them into the DECKO vector backbone and transduce target cells.

  1. 01.Design paired sgRNAs flanking your target region using CRISPETa
  2. 02.Anneal and ligate sgRNA oligos into the DECKO backbone (Addgene plasmid available)
  3. 03.Package lentivirus and transduce target cell line
  4. 04.Select transduced cells via puromycin resistance or GFP sorting
  5. 05.Screen clones by PCR/Sanger sequencing or quantify deletion rate by amplicon deep-sequencing

DECKO is a wet-lab vector system. The plasmid backbone is deposited on Addgene. Clone sgRNAs as synthesised oligos.

# Addgene plasmid deposit
Plasmid:  DECKO — #65954
Backbone: pLentiCRISPRv2-based
Selection: Puromycin / GFP dual

# Oligo design format (sense strand)
sgRNA1-F: 5'-CACCG[20nt]-3'
sgRNA1-R: 5'-AAAC[20nt-RC]C-3'

sgRNA Design Tool

CRISPETa

CRISPR Paired Excision Tool

Computational Python 3 Web interface available

Overview

CRISPETa automates the design of paired sgRNAs for CRISPR-Cas9 genomic deletion experiments. Given a genomic region of interest (e.g. a lncRNA locus), it enumerates all possible sgRNA pairs flanking the target, scores each guide for efficiency and specificity, and ranks pairs for optimal deletion design.

The tool is accessible as a command-line Python package and through a web interface, making it suitable for both computational biologists and bench scientists without programming experience. A genome-wide paired sgRNA library for systematic lncRNA deletion screens can also be generated. 

# Install via pip
pip install crispeta

# Or clone from GitHub
git clone https://github.com/gold-lab/CRISPETa
cd CRISPETa
pip install -r requirements.txt
# Basic usage: design sgRNA pairs for a target region
crispeta \
  --genome hg38 \
  --target chr7:117,120,000-117,307,000 \
  --name CFTR_lncRNA \
  --output ./output/

# Genome-wide lncRNA library design
crispeta --library-mode \
  --gtf gencode.v44.annotation.gtf \
  --biotype lncRNA \
  --pairs-per-gene 3 \
  --output ./library/

Screen Analysis

CASPR

CRISPR Analysis for Single & Paired RNA-guides

Computational R / Bioconductor Genome-wide screens

Overview

CASPR provides an end-to-end analysis pipeline for CRISPR screens targeting lncRNAs, supporting both single-guide (CRISPRi/a) and paired-guide (DECKO-style) deletion library designs. It processes raw sequencing counts from a pooled screen through quality control, normalisation, hit calling, and visualisation.

CASPR is implemented as an R/Bioconductor package and integrates with standard DESeq2 and MAGeCK workflows, providing lncRNA-aware gene-level aggregation of paired sgRNA scores. 

# Install from Bioconductor
if (!requireNamespace("BiocManager", quietly = TRUE))
  install.packages("BiocManager")
BiocManager::install("CASPR")

# Or install development version from GitHub
devtools::install_github("gold-lab/CASPR")
library(CASPR)

# Load count matrix from CRISPR screen
counts <- readCounts("screen_counts.txt")

# Run full pipeline
results <- runCASPR(
  counts   = counts,
  design   = design_matrix,
  mode     = "paired",   # or "single"
  contrast = c("condition", "treatment", "control")
)

# Visualise hits
plotVolcano(results)

Please cite

Pulido-Quetglas C, Johnson R et al. (2023). CASPR: end-to-end CRISPR screen analysis for single and paired RNA-guides. Genome Biology.

Cancer Genomics

ExInAtor

Exonic Interrogation of lncRNA cancer drivers

Cancer Python / R PCAWG validated

Overview

ExInAtor identifies cancer driver lncRNAs from whole tumour genome sequencing data. For each lncRNA gene, it compares the observed somatic mutation rate within exons against a local background model derived from the intronic and intergenic sequence flanking the gene, correcting for trinucleotide context and replication timing.

Validated on the PCAWG (PanCancer Analysis of Whole Genomes) cohort across 38 cancer types, ExInAtor identified a set of high-confidence candidate driver lncRNAs — establishing for the first time that lncRNA genes can harbour positively selected somatic driver mutations in cancer.

Key Features

—

Trinucleotide context-corrected mutation rate

—

Replication timing normalisation

—

Local background model per gene

—

FDR-controlled multiple testing

—

Compatible with MAF format input

—

PCAWG-validated on 38 cancer types

# Clone repository
git clone https://github.com/gold-lab/ExInAtor
cd ExInAtor
pip install -r requirements.txt

# Run on your somatic mutation file
python ExInAtor.py \
  --maf     somatic_mutations.maf \
  --gtf     gencode.v44.annotation.gtf \
  --genome  hg38 \
  --biotype lncRNA \
  --output  ./results/

Functional Genomics

TransCistor

Trans-Cis regulatory lncRNA identification

Computational Python 3 · Snakemake RNA-seq compatible

Overview

TransCistor is a computational pipeline for the large-scale identification of cis-regulatory lncRNAs — those that act locally to regulate the expression of adjacent protein-coding genes. Starting from RNA-seq data across multiple conditions or tissues, it identifies lncRNA–target gene pairs with significant expression correlation and spatial co-localisation on the genome.

The tool generates a ranked list of high-confidence cis-regulatory candidates, integrating co-expression strength, genomic distance, strand orientation, and conservation into a composite score. Output is compatible with downstream CRISPR validation via DECKO/CRISPETa. 

# Install via conda (recommended)
conda create -n transcistor python=3.10
conda activate transcistor
pip install transcistor

# Or from source
git clone https://github.com/gold-lab/TransCistor
cd TransCistor && pip install -e .
# Run TransCistor on a count matrix
transcistor run \
  --counts     expression_matrix.tsv \
  --gtf        gencode.v44.annotation.gtf \
  --window     500000           # 500kb cis window \
  --min-corr   0.6 \
  --fdr        0.05 \
  --output     ./transcistor_out/

# Generate summary report
transcistor report --results ./transcistor_out/

Please cite

Johnson R et al. (2024). TransCistor: efficient identification of cis-regulatory long noncoding RNAs. Bioinformatics.
